🚀 Features
Clean and responsive design.

Sections for About Me, Projects, Skills, and Contact.

Easy to customize and extend.

Ready to deploy on GitHub Pages, Netlify, or Vercel.

⚙️ Setup Instructions
Clone the repository:

bash
git clone https://github.com/amitkumar15x/portfolio.git
cd portfolio
Open index_3.html in your browser to view the portfolio.

Customize style.css and script.js if needed.

🌐 Deployment
GitHub Pages
Push your project to GitHub.

Go to Settings → Pages.

Select branch main and folder /root.

Save — your portfolio will be live at:

Code
https://amitkumar15x.github.io/portfolio
Netlify / Vercel
Import your GitHub repo.

Click Deploy.

Your portfolio will be live instantly.
